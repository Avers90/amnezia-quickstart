# 3. Защита SSH

```bash
make ssh HOST=vpn1
```

После этого:

- вход под **root** запрещён
- вход **по паролю** запрещён, только по ключу
- войти может только `admin_user`
- современные алгоритмы шифрования, лимиты на попытки входа

Плейбук подключается уже под `admin_user`. Если вход по ключу или sudo не
работают, он упадёт на подключении и ничего не изменит. Запуск под root
заблокирован.

TCP-форвардинг остаётся включён: через него работает туннель к WGDashboard
(`make panel`).

## Если потеряли ключ

Войти по SSH будет нельзя ни под root, ни по паролю. Остаётся веб-консоль
(VNC) в панели провайдера: войдите там под root и верните ключ в
`/home/<admin_user>/.ssh/authorized_keys`. Пароль root — тот, что выдал
провайдер; если вход был только по ключу, сначала сбросьте пароль root в
панели провайдера. Храните копию ключа.
