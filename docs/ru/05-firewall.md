# 5. Firewall

Ставится вместе с VPN (`make vpn`). Отдельно, например после изменения
настроек:

```bash
make firewall HOST=vpn1
make firewall HOST=vpn1 CHECK=1   # посмотреть изменения, ничего не применяя
```

> [!WARNING]
> Каждый запуск **полностью пересобирает** правила iptables. Правила,
> добавленные вручную, пропадут. Все изменения делайте через переменные.

## Что делают правила

| | |
|---|---|
| Входящие по умолчанию | запрещены |
| TCP 22 (SSH) | открыт всем |
| UDP 27015 (AmneziaWG) | открыт всем |
| UDP 443 и 51820 | перенаправляются на 27015 (запасные входы) |
| Трафик из туннеля | разрешён, выходит в интернет через NAT |
| Закрытые порты | пакеты отбрасываются молча |
| Частые подключения к SSH | больше 6 новых в минуту с одного IP отбрасываются |
| TCP MSS | ограничен до 1240 для трафика туннеля |
| IPv6 | входящие закрыты |
| Ping | разрешён |

Правила сохраняются через `netfilter-persistent` и переживают перезагрузку.

### Запасные порты

AmneziaWG слушает один порт (27015), но firewall перенаправляет на него 443 и
51820. Если оператор режет нестандартные UDP-порты, клиенту достаточно
поменять в конфиге одну строку:

```ini
Endpoint = 203.0.113.10:443
```

Остальное остаётся как есть, на сервере ничего делать не нужно.

### MSS clamp

Помогает, когда VPN подключён, мелкие сайты открываются, а крупные страницы
и загрузки висят. Обычно так бывает на мобильном интернете и PPPoE.
Действует только на TCP, для UDP/QUIC работает MTU 1376 в конфиге клиента.

## Защита SSH

Боты круглые сутки перебирают SSH. Пароли выключены, войти они не могут, но
засоряют логи и нагружают сервер. Поэтому новые подключения к порту 22 с
одного IP ограничены: 10 подряд, дальше не больше 6 в минуту. Лишние
отбрасываются, пока IP не притормозит. Списка банов нет, снимать ничего не
нужно.

Лимит действует **только на SSH**. Порты VPN не ограничены: у мобильных
операторов за одним IP сидят тысячи абонентов, и бот среди них не должен
отрезать VPN всем остальным.

> [!NOTE]
> Обычной работе лимит не мешает: `make`, `ssh` и туннель к панели держат одно
> соединение. Если же вы часто подключаетесь из скрипта и видите таймауты,
> подождите минуту или добавьте свой IP в белый список.

Закрытые порты просто молчат. Если вы случайно постучались в закрытый порт
(например, открыли в браузере `http://<IP>:10086` вместо туннеля), ничего
не случится.

### Белый список

```yaml
## local.yml
firewall_whitelist_ips:
  - 198.51.100.7
```

IP из списка не попадают под лимит SSH и имеют доступ **ко всем портам** сервера.
Для простой установки он не нужен.

> [!CAUTION]
> Добавляйте только статические адреса, которые принадлежат вам: домашний IP
> без услуги «статический IP» меняется, и потом полный доступ к серверу
> получит кто-то другой.

## Полезные команды на сервере

```bash
sudo iptables -vnL                    # правила filter
sudo iptables -vnL INPUT | grep 'limit: above'   # сколько пакетов отбросил лимит SSH
sudo cat /proc/net/ipt_hashlimit/ssh  # какие IP сейчас учитывает лимит SSH
sudo iptables -t nat -S               # NAT и перенаправление портов
sudo ipset -L WHITELIST               # белый список
```

## Настройки

`ansible/inventory/group_vars/awg/main.yml`:

| Переменная | По умолчанию | Что это |
|---|---|---|
| `firewall_public_ports_tcp` | `[22]` | открытые TCP-порты |
| `firewall_wireguard_extra_ports_udp` | `[443, 51820, 27015]` | запасные входы, порт самого AmneziaWG пропускается |
| `firewall_wireguard_mss` | `1240` | MSS clamp, `0` = выключить |
| `firewall_ssh_ratelimit` | `6/min` | лимит новых подключений к SSH с одного IP, `""` = выключить |
| `firewall_ssh_burst` | `10` | сколько подключений подряд пропускается до лимита |
| `firewall_ipv6_block` | `true` | закрыть входящий IPv6 |

Все возможности роли: [ansible-role-firewall](https://github.com/Avers90/ansible-role-firewall).

## Защита от ошибки с портом

Перед применением правил плейбук проверяет, что порт в firewall совпадает с
реальным портом AmneziaWG. Если они разойдутся, клиенты будут стучаться в
закрытый порт и VPN перестанет работать. Поэтому при
расхождении плейбук останавливается.
